# Getting Started with QuickBooks Payments Flow Project

## Quick Start (5 minutes)

### Step 1: Access the Project
Visit: https://github.com/orgs/primedigitalexchange-code/projects

Select the **"QuickBooks Payments Flow"** project from the list.

### Step 2: Understand the Workflow
```
┌──────────┐      ┌──────────────┐      ┌──────┐
│ Backlog  │ ---> │ In Progress  │ ---> │ Done │
└──────────┘      └──────────────┘      └──────┘
 (Planning)       (Development)         (Merged)
```

### Step 3: Open a Pull Request
1. Create a new branch
2. Make your changes
3. Push to GitHub
4. Open a Pull Request
5. **Your item automatically moves to "In Progress"** ✅

### Step 4: Get Review & Merge
1. Wait for code review
2. Address feedback
3. Merge your PR
4. **Your item automatically moves to "Done"** ✅

## What Happens Automatically

| Action | Result |
|--------|--------|
| PR opened | Moves to "In Progress" |
| PR reopened | Moves to "In Progress" |
| PR merged | Moves to "Done" |
| PR closed (not merged) | Stays in "In Progress" (manual update needed) |

## Manual Actions You Can Take

- **Drag items** between columns to change status
- **Add custom fields** to track additional metadata
- **Filter** by repository, author, or labels
- **Sort** by priority or date
- **Search** for specific items

## Team Guidelines

- ✅ Keep PR descriptions clear and detailed
- ✅ Link related issues in your PR
- ✅ Keep "In Progress" count low (focus over multitasking)
- ✅ Review PRs promptly to keep items moving
- ✅ Use labels consistently for better tracking

## Troubleshooting

**Q: Item didn't auto-move?**
- Manually drag it to the correct column
- Ensure automation is enabled in project settings

**Q: How do I see my PR in the project?**
- Make sure the repository is connected to the project
- You may need to refresh the page

**Q: Can I reopen a PR I closed?**
- Yes! It will move back to "In Progress" when reopened
